```markdown
# Tool Lending Library Service Specification

## Interface

The service is a Python module `solution.py` that defines a class `Service`.
Every public method returns a pair `(status, body)` where `status` is an HTTP-style integer and `body` is a `dict`, `list`, or `None`.

    class Service:
        def __init__(self, clock): ...
        def register_member(self, username, tier): ...                # 201 {"username": str, "tier": str} | 400 | 409
        def add_item(self, item_id, name, category, total_qty, duration_days): ... # 201 {"item_id": str} | 400 | 409
        def borrow_item(self, username, item_id): ...                # 201 {"loan_id": str, "due_date": float} | 400 | 404 | 403 | 409
        def return_item(self, loan_id, condition): ...               # 200 {"fine": float, "status": str} | 400 | 404
        def renew_loan(self, loan_id): ...                           # 200 {"due_date": float} | 400 | 404 | 409
        def reserve_item(self, username, item_id): ...               # 201 {"reservation_id": str} | 400 | 404 | 409
        def pay_fine(self, username, amount): ...                    # 200 {"balance": float} | 400 | 404
        def get_item(self, item_id): ...                             # 200 {"item_id": str, "name": str, "available": int, ...} | 404
        def get_member_summary(self, username): ...                  # 200 {"username": str, "tier": str, "loans": list, "fines": float} | 404

`clock` has a method `now()` returning the current time in seconds (float).

## Requirements

**REQ-1 Member Registration.** `register_member` registers a member with `username` (string) and `tier` ("standard" or "premium"). Invalid tier or empty username returns 400. If `username` already exists, returns 409. Standard members have a maximum concurrent loan limit of 3; premium members have a limit of 10.

**REQ-2 Item Cataloging.** `add_item` adds an item with `item_id`, `name`, `category`, `total_qty` (positive integer), and `duration_days` (positive integer). If `total_qty` <= 0 or `duration_days` <= 0, returns 400. If `item_id` already exists, returns 409. Initial available quantity equals `total_qty`.

**REQ-3 Borrowing Validation & Limits.** `borrow_item` allows a member to borrow an available item if: (a) member and item exist (otherwise 404); (b) member has no unpaid fines of 10.0 or greater (otherwise 403); (c) member has not reached their tier concurrent borrowing limit (otherwise 409); (d) item available quantity > 0 (otherwise 409). Successful borrow returns 201 with unique `loan_id` and calculated `due_date`.

**REQ-4 Due Date Calculation.** The `due_date` for a loan is calculated as `clock.now() + (duration_days * 86400.0)`.

**REQ-5 Returning Items.** `return_item` processes the return of a loan by `loan_id`. If loan does not exist or is already returned, returns 404. If `condition` is not one of "good", "damaged", or "lost", returns 400 (checked before or independently of loan existence, or when condition validation fails). Returning increments the item's available quantity by 1 (unless lost). If `clock.now()` exceeds `due_date`, a late fine of 2.0 per overdue calendar day (rounded up via ceiling of days) is added.

**REQ-6 Reservations.** `reserve_item` lets a member reserve an item if it exists (otherwise 404) and is currently out of stock (available == 0). If available > 0, reservation is rejected with 400. If member already has an active reservation for this item, returns 409. Returns 201 with `reservation_id`.

**REQ-7 Fines Management.** Members accumulate fines upon late returns or damaged/lost items. `pay_fine` reduces a member's fine balance by `amount` (> 0, otherwise 400). If member not found, returns 404. Returns remaining fine balance.

**REQ-8 Loan Renewal.** `renew_loan` extends an active loan's `due_date` by adding `duration_days * 86400.0` to the *current* due date. Can only be done once per loan. If loan does not exist or already returned, returns 404. If item has active reservations or loan was already renewed, renewal is rejected with 409.

**REQ-9 Condition and Damage Penalties.** When an item is returned as "damaged", a 15.0 fine is added to the member. When returned as "lost", a 50.0 fine is added, and `total_qty` of the item is permanently reduced by 1.

**REQ-10 Summaries and Queries.** `get_item` returns item details and availability (200) or 404. `get_member_summary` returns member details, active loans, reservation count, and current unpaid fines balance (200) or 404.

```

```python
"""Reference implementation of the Tool Lending Library Service."""

import math
from support import LendingException

def _is_str(x):
    return isinstance(x, str) and len(x.strip()) > 0

def _is_positive_int(x):
    return isinstance(x, int) and not isinstance(x, bool) and x > 0

def _is_positive_number(x):
    return (isinstance(x, (int, float)) and not isinstance(x, bool) and x > 0)


class Service:
    def __init__(self, clock):
        self.clock = clock
        self.members = {}       # username -> {"tier": str, "fines": float}
        self.items = {}         # item_id -> {"name": str, "category": str, "total_qty": int, "available": int, "duration_days": int}
        self.loans = {}         # loan_id -> {"username": str, "item_id": str, "due_date": float, "returned": bool, "renewed": bool}
        self.reservations = {}  # reservation_id -> {"username": str, "item_id": str}
        self._loan_counter = 0
        self._res_counter = 0

    def register_member(self, username, tier):
        if not _is_str(username) or tier not in ("standard", "premium"):
            return 400, None
        if username in self.members:
            return 409, None
        self.members[username] = {"tier": tier, "fines": 0.0}
        return 201, {"username": username, "tier": tier}

    def add_item(self, item_id, name, category, total_qty, duration_days):
        if not _is_str(item_id) or not _is_str(name) or not _is_str(category):
            return 400, None
        if not _is_positive_int(total_qty) or not _is_positive_int(duration_days):
            return 400, None
        if item_id in self.items:
            return 409, None
        self.items[item_id] = {
            "name": name,
            "category": category,
            "total_qty": total_qty,
            "available": total_qty,
            "duration_days": duration_days
        }
        return 201, {"item_id": item_id}

    def borrow_item(self, username, item_id):
        if username not in self.members or item_id not in self.items:
            return 404, None
        member = self.members[username]
        if member["fines"] >= 10.0:
            return 403, None
        item = self.items[item_id]
        if item["available"] <= 0:
            return 409, None
        
        limit = 10 if member["tier"] == "premium" else 3
        active_loans_count = sum(
            1 for l in self.loans.values()
            if l["username"] == username and not l["returned"]
        )
        if active_loans_count >= limit:
            return 409, None

        self._loan_counter += 1
        loan_id = f"L{self._loan_counter}"
        due_date = self.clock.now() + (item["duration_days"] * 86400.0)

        item["available"] -= 1
        self.loans[loan_id] = {
            "username": username,
            "item_id": item_id,
            "due_date": due_date,
            "returned": False,
            "renewed": False
        }
        return 201, {"loan_id": loan_id, "due_date": due_date}

    def return_item(self, loan_id, condition):
        if condition not in ("good", "damaged", "lost"):
            return 400, None
        if not _is_str(loan_id) or loan_id not in self.loans:
            return 404, None
        loan = self.loans[loan_id]
        if loan["returned"]:
            return 404, None

        loan["returned"] = True
        item = self.items[loan["item_id"]]
        
        fine = 0.0
        now = self.clock.now()
        if now > loan["due_date"]:
            overdue_seconds = now - loan["due_date"]
            overdue_days = math.ceil(overdue_seconds / 86400.0)
            fine += overdue_days * 2.0

        if condition == "damaged":
            fine += 15.0
            item["available"] += 1
        elif condition == "lost":
            fine += 50.0
            item["total_qty"] = max(0, item["total_qty"] - 1)
        else:
            item["available"] += 1

        if fine > 0.0:
            self.members[loan["username"]]["fines"] += fine

        return 200, {"fine": fine, "status": condition}

    def renew_loan(self, loan_id):
        if not _is_str(loan_id) or loan_id not in self.loans:
            return 404, None
        loan = self.loans[loan_id]
        if loan["returned"] or loan["renewed"]:
            return 409, None

        item_id = loan["item_id"]
        has_reservation = any(
            r["item_id"] == item_id for r in self.reservations.values()
        )
        if has_reservation:
            return 409, None

        item = self.items[item_id]
        loan["due_date"] += item["duration_days"] * 86400.0
        loan["renewed"] = True
        return 200, {"due_date": loan["due_date"]}

    def reserve_item(self, username, item_id):
        if username not in self.members or item_id not in self.items:
            return 404, None
        item = self.items[item_id]
        if item["available"] > 0:
            return 400, None

        already_reserved = any(
            r["username"] == username and r["item_id"] == item_id
            for r in self.reservations.values()
        )
        if already_reserved:
            return 409, None

        self._res_counter += 1
        res_id = f"R{self._res_counter}"
        self.reservations[res_id] = {"username": username, "item_id": item_id}
        return 201, {"reservation_id": res_id}

    def pay_fine(self, username, amount):
        if username not in self.members or not _is_positive_number(amount):
            return 400, None if username not in self.members else 400
        member = self.members[username]
        member["fines"] = max(0.0, member["fines"] - amount)
        return 200, {"balance": member["fines"]}

    def get_item(self, item_id):
        if item_id not in self.items:
            return 404, None
        item = self.items[item_id]
        return 200, {
            "item_id": item_id,
            "name": item["name"],
            "category": item["category"],
            "total_qty": item["total_qty"],
            "available": item["available"],
            "duration_days": item["duration_days"]
        }

    def get_member_summary(self, username):
        if username not in self.members:
            return 404, None
        member = self.members[username]
        active_loans = [
            {"loan_id": lid, "item_id": l["item_id"], "due_date": l["due_date"], "renewed": l["renewed"]}
            for lid, l in self.loans.items()
            if l["username"] == username and not l["returned"]
        ]
        res_count = sum(
            1 for r in self.reservations.values() if r["username"] == username
        )
        return 200, {
            "username": username,
            "tier": member["tier"],
            "loans": active_loans,
            "reservations_count": res_count,
            "fines": member["fines"]
        }

```

```python
"""Visible tests T_v of the tool lending library service (nominal cases)."""
from solution import Service


class Clock:
    def __init__(self, t=0.0):
        self.t = t

    def now(self):
        return self.t


def test_register_and_get_member():
    svc = Service(Clock())
    assert svc.register_member("alice", "standard") == (201, {"username": "alice", "tier": "standard"})
    status, body = svc.get_member_summary("alice")
    assert status == 200
    assert body["username"] == "alice"
    assert body["tier"] == "standard"
    assert body["fines"] == 0.0


def test_add_item_and_get():
    svc = Service(Clock())
    assert svc.add_item("t1", "Drill", "Power Tools", 2, 7) == (201, {"item_id": "t1"})
    status, body = svc.get_item("t1")
    assert status == 200
    assert body["available"] == 2
    assert body["total_qty"] == 2


def test_borrow_and_return():
    svc = Service(Clock(100.0))
    svc.register_member("bob", "standard")
    svc.add_item("t1", "Drill", "Power Tools", 1, 7)
    
    b_status, b_body = svc.borrow_item("bob", "t1")
    assert b_status == 201
    assert "loan_id" in b_body
    
    r_status, r_body = svc.return_item(b_body["loan_id"], "good")
    assert r_status == 200
    assert r_body["fine"] == 0.0
    assert r_body["status"] == "good"


def test_renew_loan():
    svc = Service(Clock(100.0))
    svc.register_member("charlie", "standard")
    svc.add_item("t1", "Saw", "Hand Tools", 1, 5)
    
    _, b_body = svc.borrow_item("charlie", "t1")
    renew_status, renew_body = svc.renew_loan(b_body["loan_id"])
    assert renew_status == 200
    assert renew_body["due_date"] > b_body["due_date"]


def test_pay_fine():
    svc = Service(Clock())
    svc.register_member("dave", "standard")
    svc.members["dave"]["fines"] = 15.0
    
    status, body = svc.pay_fine("dave", 10.0)
    assert status == 200
    assert body["balance"] == 5.0
```

```python
        else:
```

### FILE: AUTHOR_NOTES.md

```markdown
# Author Notes

## Design Choices
- **Domain**: Tool Lending Library service managing members, item catalog, loans, reservations, and fines.
- **State management**: Kept entirely in-memory using dictionaries indexed by IDs and usernames, injected with a `clock` object for time-dependent calculations.
- **Fines & Penalties**: Overdue returns accrue fines per day (calculated via ceiling of overdue seconds divided by 86400.0). Damage and loss incur flat penalties and inventory adjustments.

## Behaviors Deliberately Left Open
- The exact tie-breaking order when multiple members reserve the same out-of-stock item is not specified (reservations are stored in a dictionary and checked generically).
- Whether partial seconds of overdue time should trigger a full day fine immediately (handled via `math.ceil`).

## Seeded Fault Rationales
- **F01**: A developer might validate only that a username is present and forget to validate the membership tier string against allowed values.
- **F02**: A developer might check that parameters are integers but forget to enforce that quantities and durations must be strictly positive (> 0).
- **F03**: A developer might use a strict greater-than operator (`> 10.0`) instead of greater-than-or-equal (`>= 10.0`) when checking unpaid fines.
- **F04**: A developer might hardcode the maximum concurrent loan limit to 10 for all tiers during a quick prototype and forget to implement tier-based limits.
- **F05**: A developer might use `math.floor` instead of `math.ceil` when calculating overdue days, undercharging members for partial overdue days.
```
