```markdown
# Equipment Loan Service

A small in‑process service that models a lab/library lending physical equipment
items to registered users. State evolves through an injected clock.

## Interface

The service is a Python module `solution.py` defining one class `Service`.
Every public method returns a pair `(status, body)` where `status` is an
HTTP‑style integer and `body` is a `dict`, a `list`, or `None`.

    class Service:
        def __init__(self, clock, max_loans=3, max_renewals=2, loan_period=7.0): ...
        def register_user(self, user_id, role): ...     # 201 | 400 | 409
        def add_item(self, item_id, name): ...           # 201 | 400 | 409
        def checkout(self, user_id, item_id): ...        # 200 | 404 | 409 | 422
        def return_loan(self, user_id, loan_id): ...     # 200 | 404 | 403 | 409
        def renew_loan(self, user_id, loan_id): ...      # 200 | 404 | 403 | 409 | 422
        def list_loans(self, user_id): ...               # 200 | 404
        def item_status(self, item_id): ...              # 200 | 404

`clock` is any object exposing `now()` returning a float (seconds). All time
decisions use only `clock.now()`; the wall clock is never read.

Constructor parameters: `max_loans` and `max_renewals` are non‑negative
integers, `loan_period` a positive number. Their exact validation beyond the
stated types/ranges is left open.

Roles are exactly `"member"` and `"staff"`. An identifier (`user_id`,
`item_id`) or `name` is valid iff it is a non‑empty `str`.

## Response bodies

- `register_user` 201: `{"user_id": str, "role": str}`
- `add_item` 201: `{"item_id": str, "name": str}`
- `checkout` 200: `{"loan_id": int, "due_at": float}`
- `return_loan` 200: `{"item_id": str}`
- `renew_loan` 200: `{"due_at": float}`
- `list_loans` 200: a `list` of loan objects, each
  `{"loan_id": int, "item_id": str, "due_at": float,
  "renewals_used": int, "status": str}` where `status` is `"active"` or
  `"returned"`.
- `item_status` 200: `{"available": bool, "loan_id": int | None}`

## Requirements

**REQ‑1 Register user.** `register_user` creates a user. If `user_id` or
`role` is invalid (see above) return 400. If `user_id` already exists return
409. Otherwise store the role and return 201 with the body above.

**REQ‑2 Add item.** `add_item` adds catalog inventory keyed by `item_id`.
If `item_id` or `name` is invalid return 400. If `item_id` already exists
return 409. Two distinct items may share the same `name`. Otherwise return
201 with the body above.

**REQ‑3 Checkout.** Checks run in this order, first match wins:
1. If `user_id` is not registered return 404.
2. If `item_id` is not in the catalog return 404.
3. If the item currently has an active loan return 409.
4. If the user already has `max_loans` or more active loans return 422.
Otherwise create a new loan: assign the next sequential `loan_id` starting at
1, record `user_id`, `item_id`, `due_at = clock.now() + loan_period`,
`renewals_used = 0`, `status = "active"`, mark the item as on loan, and
return 200 with `{"loan_id", "due_at"}`.

**REQ‑4 Return loan.** Checks run in this order:
1. If `loan_id` is unknown return 404.
2. If the loan is not owned by `user_id` and the caller's role is not
   `"staff"` return 403.
3. If the loan's status is already `"returned"` return 409.
Otherwise set its status to `"returned"`, free the item (it becomes available
again), and return 200 with `{"item_id"}`.

**REQ‑5 Renew loan.** Checks run in this order:
1. If `loan_id` is unknown return 404.
2. If the loan is not owned by `user_id` and the caller's role is not
   `"staff"` return 403.
3. If the loan's status is `"returned"` return 409.
4. If `clock.now() > due_at` (strictly overdue) return 409.
5. If `renewals_used >= max_renewals` return 422.
Otherwise set `due_at = due_at + loan_period`, increment `renewals_used`, and
return 200 with `{"due_at"}`.

**REQ‑6 List loans.** If `user_id` is not registered return 404. Otherwise
return every loan ever created for that user (active and returned), as a list
sorted by `loan_id` ascending, using the loan object shape above.

**REQ‑7 Item status.** If `item_id` is not in the catalog return 404.
Otherwise `available` is `True` iff the item has no active loan; `loan_id` is
that active loan's id, or `None` if available.

**REQ‑8 Staff privilege.** A `"staff"` user may call `return_loan` and
`renew_loan` on any loan regardless of ownership. A `"member"` may act only
on loans they own (otherwise 403). This applies to the ownership check in
REQ‑4 step 2 and REQ‑5 step 2.

**REQ‑9 Limits are configurable.** `max_loans` caps simultaneous active loans
per user (REQ‑3 step 4) and `max_renewals` caps renewals per loan (REQ‑5
step 5). With the defaults (3 and 2) a user may hold at most 3 active loans
and renew a loan at most 2 times.

**REQ‑10 Time comes from the clock.** Every `due_at` value and every
overdue decision is derived solely from `clock.now()` at the moment of the
relevant call; no other time source is consulted.
```

```python
"""Reference implementation of the Equipment Loan Service."""


def _is_nonempty_str(x):
    return isinstance(x, str) and len(x) > 0


_ROLES = ("member", "staff")


class Service:
    def __init__(self, clock, max_loans=3, max_renewals=2, loan_period=7.0):
        self.clock = clock
        self.max_loans = max_loans
        self.max_renewals = max_renewals
        self.loan_period = loan_period
        self._users = {}            # user_id -> role
        self._items = {}            # item_id -> name
        self._loans = {}            # loan_id -> loan dict
        self._item_loan = {}        # item_id -> active loan_id
        self._next_loan_id = 1

    # ---- helpers -------------------------------------------------------
    def _active_count(self, user_id):
        n = 0
        for loan in self._loans.values():
            if loan["user"] == user_id and loan["status"] == "active":
                n += 1
        return n

    def _owned_or_staff(self, user_id, loan):
        if loan["user"] == user_id:
            return True
        return self._users.get(user_id) == "staff"

    # ---- REQ-1 ---------------------------------------------------------
    def register_user(self, user_id, role):
        if not (_is_nonempty_str(user_id) and role in _ROLES):
            return 400, None
        if user_id in self._users:
            return 409, None
        self._users[user_id] = role
        return 201, {"user_id": user_id, "role": role}

    # ---- REQ-2 ---------------------------------------------------------
    def add_item(self, item_id, name):
        if not (_is_nonempty_str(item_id) and _is_nonempty_str(name)):
            return 400, None
        if item_id in self._items:
            return 409, None
        self._items[item_id] = name
        return 201, {"item_id": item_id, "name": name}

    # ---- REQ-3 ---------------------------------------------------------
    def checkout(self, user_id, item_id):
        if user_id not in self._users:
            return 404, None
        if item_id not in self._items:
            return 404, None
        if item_id in self._item_loan:
            return 409, None
        if self._active_count(user_id) >= self.max_loans:
            return 422, None
        loan_id = self._next_loan_id
        self._next_loan_id += 1
        due_at = self.clock.now() + self.loan_period
        self._loans[loan_id] = {
            "id": loan_id,
            "user": user_id,
            "item": item_id,
            "due_at": due_at,
            "renewals_used": 0,
            "status": "active",
        }
        self._item_loan[item_id] = loan_id
        return 200, {"loan_id": loan_id, "due_at": due_at}

    # ---- REQ-4 ---------------------------------------------------------
    def return_loan(self, user_id, loan_id):
        loan = self._loans.get(loan_id)
        if loan is None:
            return 404, None
        if not self._owned_or_staff(user_id, loan):
            return 403, None
        if loan["status"] == "returned":
            return 409, None
        loan["status"] = "returned"
        self._item_loan.pop(loan["item"], None)
        return 200, {"item_id": loan["item"]}

    # ---- REQ-5 ---------------------------------------------------------
    def renew_loan(self, user_id, loan_id):
        loan = self._loans.get(loan_id)
        if loan is None:
            return 404, None
        if not self._owned_or_staff(user_id, loan):
            return 403, None
        if loan["status"] == "returned":
            return 409, None
        if self.clock.now() > loan["due_at"]:
            return 409, None
        if loan["renewals_used"] >= self.max_renewals:
            return 422, None
        loan["due_at"] = loan["due_at"] + self.loan_period
        loan["renewals_used"] += 1
        return 200, {"due_at": loan["due_at"]}

    # ---- REQ-6 ---------------------------------------------------------
    def list_loans(self, user_id):
        if user_id not in self._users:
            return 404, None
        rows = []
        for loan in self._loans.values():
            if loan["user"] == user_id:
                rows.append({
                    "loan_id": loan["id"],
                    "item_id": loan["item"],
                    "due_at": loan["due_at"],
                    "renewals_used": loan["renewals_used"],
                    "status": loan["status"],
                })
        rows.sort(key=lambda r: r["loan_id"])
        return 200, rows

    # ---- REQ-7 ---------------------------------------------------------
    def item_status(self, item_id):
        if item_id not in self._items:
            return 404, None
        loan_id = self._item_loan.get(item_id)
        return 200, {"available": loan_id is None, "loan_id": loan_id}
```

```python
from solution import Service


class Clock:
    def __init__(self, t=1000.0):
        self.t = t

    def now(self):
        return self.t


def test_register_and_add_item():
    svc = Service(Clock())
    assert svc.register_user("ann", "member") == (201, {"user_id": "ann", "role": "member"})
    assert svc.add_item("scope-1", "Oscilloscope") == (201, {"item_id": "scope-1", "name": "Oscilloscope"})


def test_checkout_then_return_lists_loan():
    svc = Service(Clock())
    svc.register_user("ann", "member")
    svc.add_item("scope-1", "Oscilloscope")
    st, body = svc.checkout("ann", "scope-1")
    assert st == 200
    loan_id = body["loan_id"]
    assert isinstance(loan_id, int)
    st2, body2 = svc.return_loan("ann", loan_id)
    assert st2 == 200 and body2 == {"item_id": "scope-1"}
    st3, loans = svc.list_loans("ann")
    assert st3 == 200
    assert len(loans) == 1
    assert loans[0]["loan_id"] == loan_id
    assert loans[0]["status"] == "returned"


def test_renew_nominal():
    svc = Service(Clock())
    svc.register_user("bob", "member")
    svc.add_item("drill", "Cordless drill")
    _, c = svc.checkout("bob", "drill")
    due0 = c["due_at"]
    st, r = svc.renew_loan("bob", c["loan_id"])
    assert st == 200
    assert r["due_at"] > due0
    _, loans = svc.list_loans("bob")
    assert loans[0]["renewals_used"] == 1


def test_item_available_before_checkout():
    svc = Service(Clock())
    svc.add_item("multimeter", "Multimeter")
    st, s = svc.item_status("multimeter")
    assert st == 200 and s == {"available": True, "loan_id": None}


def test_unknown_item_status_404():
    svc = Service(Clock())
    assert svc.item_status("nope")[0] == 404
```

```python
# ---------------- stateful model ----------------
class Loans(RuleBasedStateMachine):
    def __init__(self):
        super().__init__()
        self.clk = Clock(100.0)
        self.svc = Service(self.clk, max_loans=2, max_renewals=1, loan_period=10.0)
        self.users = {}      # uid -> role
        self.items = set()
        self.loans = {}      # lid -> dict
        self.next_lid = 1

    @initialize()
    def seed(self):
        for u in ("ann", "bob"):
            self.svc.register_user(u, "member")
            self.users[u] = "member"
        self.svc.register_user("admin", "staff")
        self.users["admin"] = "staff"
        for i in ("x", "y", "z"):
            self.svc.add_item(i, "N")
            self.items.add(i)

    @rule(tick=st.integers(0, 30))
    def advance_time(self, tick):
        self.clk.t += float(tick)

    @rule(uid=st.sampled_from(["ann", "bob"]), iid=st.sampled_from(["x", "y", "z"]))
    def checkout(self, uid, iid):
        active_for_user = sum(1 for L in self.loans.values()
                              if L["user"] == uid and L["status"] == "active")
        on_loan = any(L["item"] == iid and L["status"] == "active" for L in self.loans.values())
        stt, body = self.svc.checkout(uid, iid)
        if on_loan:
            assert stt == 409
        elif active_for_user >= 2:
            assert stt == 422
        else:
            assert stt == 200
            assert body["loan_id"] == self.next_lid
            self.loans[self.next_lid] = {
                "user": uid, "item": iid,
                "due_at": self.clk.t + 10.0, "renewals_used": 0, "status": "active",
            }
            self.next_lid += 1

    @rule(lid=st.integers(1, 3))
    def return_loan(self, lid):
        L = self.loans.get(lid)
        stt, body = self.svc.return_loan("admin", lid)
        if L is None:
            assert stt == 404
        elif L["status"] == "returned":
            assert stt == 409
        else:
            assert stt == 200 and body["item_id"] == L["item"]
            L["status"] = "returned"

    @rule(lid=st.integers(1, 3))
    def renew_loan(self, lid):
        L = self.loans.get(lid)
        stt, body = self.svc.renew_loan("admin", lid)
        if L is None:
            assert stt == 404
        elif L["status"] == "returned":
            assert stt == 409
        elif self.clk.t > L["due_at"]:
            assert stt == 409
        elif L["renewals_used"] >= 1:
            assert stt == 422
        else:
            assert stt == 200
            L["due_at"] += 10.0
            L["renewals_used"] += 1
            assert body["due_at"] == L["due_at"]
```

```markdown
# Author notes

## Design choices

- Domain: physical equipment loans (catalog + users + loans). Chosen because it
  exercises shared mutable resources, per-user quotas, time-based rules, and a
  role-based override, while staying in-process and deterministic.
- Status codes follow the usual REST-ish convention: 200/201 success, 400 bad
  input, 403 forbidden, 404 not found, 409 conflict, 422 unprocessable.
- Check-order precedence (REQ-3/4/5) is spelled out in the spec so hidden tests
  can rely on a single observable code for overlapping conditions.

## Behaviors deliberately left open (NOT tested)

- Exact validation of the constructor arguments (`max_loans`, `max_renewals`,
  `loan_period`) beyond the documented types/ranges.
- Whether `return_loan`/`renew_loan` of a *nonexistent* id is reported before
  or after an ownership failure — the spec fixes existence first, so only that
  order is tested; nothing else about error precedence outside the listed steps.
- Internal representation of `loan_id` (only the sequence-from-1 property is
  specified).
- Tie-breaking is impossible (ids unique), so ordering stability is unspecified.
- Behavior of registering with a name identical to another user's id is not a
  concept here; ids are global keys.

## Why each fault is plausible (one line each)

- **F01**: copy-pasting a longer role list from another product's docs.
- **F02**: "just overwrite" convenience that quietly kills the conflict code.
- **F03**: confusing business-level uniqueness (by name) with key uniqueness.
- **F04**: using `* 2` instead of `+ period` when wiring the extension formula.
- **F05**: zero-based indexing habit leaking into a public id sequence.
- **F06**: forgetting the side-effect line that reserves the resource.
- **F07**: `>=` vs `>` boundary mistake on a quota check.
- **F08**: removing a guard during a refactor that assumed callers were trusted.
- **F09**: updating status but forgetting the companion release of the lock.
- **F10**: inclusive-vs-exclusive comparison on a deadline.
- **F11**: resetting a counter instead of incrementing it.
- **F12**: mirror-image boundary slip on the renewal cap.
- **F13**: dropping a filter predicate while optimizing iteration.
- **F14**: forgetting to forward the loan id into the response dict.
- **F15**: stubbing out a permission branch and leaving the stub in place.
```
