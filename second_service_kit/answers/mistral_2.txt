```markdown
# Room reservation service

A service that manages meeting rooms. Users book seats in a room for a time
interval on a given day. A room's capacity is shared by all overlapping
bookings. Users can cancel or move their bookings and list them.

The service is stateful and in-process. It never reads the system clock and
never uses randomness: all time information comes from the injected clock.

## Interface

The service is a Python module `solution.py` that defines a class `Service`.
The constructor takes one argument, a clock object with a method `today()`
that returns the current day number as an integer.

Every public method returns a pair `(status, body)`. `status` is an HTTP-style
integer. `body` is a dict, a list, or None. The body is None for every status
that is not 2xx.

A booking record is a dict with exactly these keys:

    {"booking_id": int, "room": str, "day": int, "start": int, "end": int, "seats": int}

    class Service:
        def __init__(self, clock): ...
        def create_room(self, room, capacity): ...
            # 201 {"room": str} | 400 None | 409 None
        def book(self, user, room, day, start, end, seats): ...
            # 201 booking record | 404 None | 400 None | 409 None
        def cancel(self, user, booking_id): ...
            # 200 {"status": "cancelled"} | 404 None | 409 None
        def move(self, user, booking_id, new_day, new_start, new_end): ...
            # 200 booking record | 404 None | 400 None | 409 None
        def list_bookings(self, user): ...
            # 200 list of booking records

## Requirements

**REQ-1 Room creation.** `create_room(room, capacity)` registers a room.
`room` must be a string that is non-empty and has no leading or trailing
whitespace; `capacity` must be an integer with 1 <= capacity <= 50. If either
is invalid the method returns 400. A bool is not an integer anywhere in this
specification. If a room with the same name already exists it returns 409.
Validation (400) is checked before existence (409). On success it returns
201 with body {"room": room}.

**REQ-2 Time validity.** A time is a triple (day, start, end) where day,
start and end are integers (bools rejected) with 0 <= day <= 365,
day >= clock.today(), 0 <= start < end <= 24. The interval occupied by a
booking is [start, end) in whole hours. Any method given an invalid time
returns 400 and changes nothing.

**REQ-3 Booking.** `book(user, room, day, start, end, seats)` checks, in this
order: the room must exist, else 404; the time must be valid (REQ-2), else
400; `seats` must be an integer with 1 <= seats <= the room's capacity,
else 400; the capacity constraint (REQ-4) must hold, else 409.

**REQ-4 Capacity.** For every hour h in [start, end), the sum of the seats of
all active bookings in that room, on that day, covering hour h, must not
exceed the room's capacity. A booking request that would violate this for at
least one hour returns 409 and changes nothing.

**REQ-5 Identifiers.** Every successful booking receives a `booking_id`:
integers starting at 1, increasing by 1 for each new booking, unique across
all bookings ever made, never reused. On success `book` returns 201 with the
booking record.

**REQ-6 Ownership.** A booking belongs to the user who created it. For
`cancel`, `move` and `list_bookings`, a booking id that does not exist and a
booking id owned by another user are both handled exactly as a missing
booking: 404 for `cancel` and `move`. `list_bookings(user)` returns only that
user's bookings.

**REQ-7 Cancellation.** `cancel(user, booking_id)` on an active booking owned
by the user returns 200 with body {"status": "cancelled"}; the booking becomes
cancelled and its seats stop counting for REQ-4. Cancelling a booking that is
already cancelled returns 409.

**REQ-8 Move.** `move(user, booking_id, new_day, new_start, new_end)` moves
the booking to a new time in the same room with the same seats; it cannot
change the room or the seat count. Checks in this order: the booking must
exist and belong to the user (REQ-6), else 404; it must be active, else 409;
the new time must be valid (REQ-2), else 400; the capacity constraint
(REQ-4) must hold for the new time, else 409. For the capacity check the
booking's own current seats do not count as usage at hours it currently
occupies. On success it returns 200 with the booking record updated to the
new day, start and end. On any failure the booking and all capacity state are
unchanged.

**REQ-9 Listing.** `list_bookings(user)` returns 200 and a list of the
user's active bookings, each a booking record with exactly the keys of REQ-5,
sorted by (day, start, booking_id) ascending. A user with no active bookings
gets an empty list.

**REQ-10 Cancelled bookings.** A cancelled booking keeps its identifier, does
not occupy any capacity, does not appear in listings, and can be neither
cancelled again (REQ-7) nor moved (REQ-8).
```

```python
"""Reference implementation of the room reservation service."""


def _is_int(x):
    return isinstance(x, int) and not isinstance(x, bool)


class Service:
    def __init__(self, clock):
        self.clock = clock
        self._rooms = {}       # room -> capacity
        self._bookings = {}    # booking_id -> record
        self._grid = {}        # (room, day) -> list of 24 seat counts
        self._next_id = 1

    def create_room(self, room, capacity):
        if not (isinstance(room, str) and room != "" and room.strip() == room):
            return 400, None
        if not (_is_int(capacity) and 1 <= capacity <= 50):
            return 400, None
        if room in self._rooms:
            return 409, None
        self._rooms[room] = capacity
        return 201, {"room": room}

    def _valid_time(self, day, start, end):
        if not (_is_int(day) and 0 <= day <= 365):
            return False
        if day < self.clock.today():
            return False
        if not (_is_int(start) and _is_int(end) and 0 <= start < end <= 24):
            return False
        return True

    def _fits(self, room, day, start, end, seats, exclude_id=None):
        booked = self._grid.setdefault((room, day), [0] * 24)
        for h in range(start, end):
            used = booked[h]
            if exclude_id is not None:
                own = self._bookings[exclude_id]
                if own["room"] == room and own["day"] == day and own["start"] <= h < own["end"]:
                    used -= own["seats"]
            if used + seats > self._rooms[room]:
                return False
        return True

    def book(self, user, room, day, start, end, seats):
        if room not in self._rooms:
            return 404, None
        if not self._valid_time(day, start, end):
            return 400, None
        if not (_is_int(seats) and 1 <= seats <= self._rooms[room]):
            return 400, None
        if not self._fits(room, day, start, end, seats):
            return 409, None
        grid = self._grid.setdefault((room, day), [0] * 24)
        for h in range(start, end):
            grid[h] += seats
        booking_id = self._next_id
        self._next_id += 1
        rec = {"booking_id": booking_id, "room": room, "day": day,
               "start": start, "end": end, "seats": seats,
               "user": user, "status": "active"}
        self._bookings[booking_id] = rec
        return 201, {"booking_id": booking_id, "room": room, "day": day,
                     "start": start, "end": end, "seats": seats}

    def cancel(self, user, booking_id):
        b = self._bookings.get(booking_id)
        if b is None or b["user"] != user:
            return 404, None
        if b["status"] != "active":
            return 409, None
        booked = self._grid[(b["room"], b["day"])]
        for h in range(b["start"], b["end"]):
            booked[h] -= b["seats"]
        b["status"] = "cancelled"
        return 200, {"status": "cancelled"}

    def move(self, user, booking_id, new_day, new_start, new_end):
        b = self._bookings.get(booking_id)
        if b is None or b["user"] != user:
            return 404, None
        if b["status"] != "active":
            return 409, None
        if not self._valid_time(new_day, new_start, new_end):
            return 400, None
        if not self._fits(b["room"], new_day, new_start, new_end, b["seats"], exclude_id=booking_id):
            return 409, None
        old = self._grid[(b["room"], b["day"])]
        for h in range(b["start"], b["end"]):
            old[h] -= b["seats"]
        new = self._grid.setdefault((b["room"], new_day), [0] * 24)
        for h in range(new_start, new_end):
            new[h] += b["seats"]
        b["day"], b["start"], b["end"] = new_day, new_start, new_end
        return 200, {"booking_id": booking_id, "room": b["room"], "day": new_day,
                     "start": new_start, "end": new_end, "seats": b["seats"]}

    def list_bookings(self, user):
        recs = [b for b in self._bookings.values()
                if b["user"] == user and b["status"] == "active"]
        recs.sort(key=lambda b: (b["day"], b["start"], b["booking_id"]))
        return 200, [{"booking_id": b["booking_id"], "room": b["room"],
                      "day": b["day"], "start": b["start"], "end": b["end"],
                      "seats": b["seats"]} for b in recs]
```

```python
# ---- Model-based stateful test of REQ-2, REQ-4, REQ-5, REQ-7, REQ-8, REQ-9, REQ-10 ----

class Reservations(RuleBasedStateMachine):
    CAP = 6

    def __init__(self):
        super().__init__()
        self.svc = Service(Clock(0))
        assert self.svc.create_room("r", self.CAP)[0] == 201
        self.usage = {}     # (day, hour) -> seats in use
        self.recs = {}      # booking_id -> {"day", "start", "end", "seats"}
        self.dead = set()   # cancelled booking ids
        self.next_id = 1

    def _expected_list(self):
        active = [i for i in self.recs if i not in self.dead]
        active.sort(key=lambda i: (self.recs[i]["day"], self.recs[i]["start"], i))
        return [{"booking_id": i, "room": "r", "day": self.recs[i]["day"],
                 "start": self.recs[i]["start"], "end": self.recs[i]["end"],
                 "seats": self.recs[i]["seats"]} for i in active]

    @invariant()
    def list_matches_model(self):
        assert self.svc.list_bookings("ann") == (200, self._expected_list())

    @rule(day=st.sampled_from([5, 6]), start=st.integers(0, 21),
          length=st.integers(1, 3), seats=st.integers(1, 6))
    def book(self, day, start, length, seats):
        end = start + length
        status, body = self.svc.book("ann", "r", day, start, end, seats)
        conflict = any(self.usage.get((day, h), 0) + seats > self.CAP
                       for h in range(start, end))
        if conflict:
            assert status == 409
        else:
            assert status == 201
            assert body["booking_id"] == self.next_id
            self.next_id += 1
            for h in range(start, end):
                self.usage[(day, h)] = self.usage.get((day, h), 0) + seats
            self.recs[body["booking_id"]] = {"day": day, "start": start,
                                             "end": end, "seats": seats}

    @rule(bid=st.integers(1, 20))
    def cancel(self, bid):
        status, body = self.svc.cancel("ann", bid)
        r = self.recs.get(bid)
        if r is None:
            assert status == 404
        elif bid in self.dead:
            assert status == 409
        else:
            assert status == 200 and body == {"status": "cancelled"}
            for h in range(r["start"], r["end"]):
                self.usage[(r["day"], h)] -= r["seats"]
            self.dead.add(bid)

    @rule(bid=st.integers(1, 20), day=st.sampled_from([5, 6]),
          start=st.integers(0, 21), length=st.integers(1, 3))
    def move(self, bid, day, start, length):
        end = start + length
        r = self.recs.get(bid)
        status, body = self.svc.move("ann", bid, day, start, end)
        if r is None:
            assert status == 404
        elif bid in self.dead:
            assert status == 409
        else:
            conflict = False
            for h in range(start, end):
                used = self.usage.get((day, h), 0)
                if r["day"] == day and r["start"] <= h < r["end"]:
                    used -= r["seats"]
                if used + r["seats"] > self.CAP:
                    conflict = True
            if conflict:
                assert status == 409
            else:
                assert status == 200
                for h in range(r["start"], r["end"]):
                    self.usage[(r["day"], h)] -= r["seats"]
                for h in range(start, end):
                    self.usage[(day, h)] = self.usage.get((day, h), 0) + r["seats"]
                r["day"], r["start"], r["end"] = day, start, end
```

```markdown
# Author notes — room reservation service

## Design choices

- Domain: shared-capacity room reservations. Capacity is a *shared* resource
  (overlapping bookings allowed until the seat sum exceeds capacity), which
  gives richer state than pure exclusive booking and realistic conflicts.
- The clock is injected and only used via `clock.today()`; nothing else in the
  service is time- or randomness-dependent, so all tests are deterministic.
- Internal model: per (room, day) a 24-slot array of seats in use; per booking
  a record with user and status.
- Spec fixes check *order* for `book` (404, 400, 400, 409) and `move`
  (404, 409, 400, 409) so that ambiguous-input tests are spec-derived, not
  implementation-derived.
- Error bodies are always None (stated in the spec).
- T_v is deliberately nominal: it never asserts exact booking ids, never
  books for "today", never books to exact capacity, never re-books a released
  slot, and never tests duplicate rooms, ownership, double cancel, or list
  ordering — so all 17 faults pass T_v. Each fault is caught by a named
  deterministic T_h test (plus the stateful machine for several of them).

## Fix history (validator round 1)

- `test_req8_move_conflict_leaves_unchanged` originally booked Bob on 10–12
  seats 2 against Ann's 9–11 seats 3 with capacity 4; that booking itself
  violates REQ-4 (3 + 2 > 4 on hour 10) and was silently rejected, so the
  later move to 11–13 was in fact legal and correctly returned 200. The test
  was a design error, not a reference bug. It was rewritten so that Bob's
  booking (12–14, seats 2) is valid and the move (to 10–12) genuinely violates
  REQ-4 on hour 12 (2 + 3 > 4). The spec required no change.
- Fault F03's original text was missing the `and` between `_is_int(end)` and
  the range comparison; it now matches reference.py exactly.
```
